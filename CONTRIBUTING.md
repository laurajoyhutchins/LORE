# Contributing

LORE is in maintenance mode. Bug fixes, safety improvements, deterministic behavior, and reductions in consumer maintenance burden are welcome.

Feature proposals must name a current consumer problem and a measurable benefit. Platform expansion without consumer evidence is out of scope.

Development:

```bash
corepack enable
pnpm install
pnpm ci
```

Reviewed repository knowledge changes use normal Git commits and pull requests. There is no LORE-specific proposal or apply lifecycle.
