# Maintenance mode

LORE is in maintenance and contraction mode.

The supported product is limited to deterministic extraction, reviewed-knowledge validation, concise projections, safe initialization, and bounded deterministic context selection.

Feature work is not justified by internal coherence alone. A new capability must identify a current consumer problem and show a measurable reduction in consumer files, CI cost, bookkeeping, agent reasoning, or failure risk.

The following are explicitly outside LORE's roadmap:

- proposal/apply transaction protocols or transaction receipts
- semantic history that duplicates Git history
- causal graph or DAG product features
- causal traversal, explanation, or coverage invariants
- Deciduous compatibility projections or translation layers
- hydration or autonomous knowledge-management workflows
- generalized agent orchestration
- consumer verification of LORE's own trust, release, or self-hosting internals

Git commits, branches, diffs, pull requests, review, and merge history are the ordinary change and provenance mechanism.

Self-hosting is permitted only as small dogfooding inside this repository. It must not expand the public contract or consumer footprint.
